# DETOXY privacy policy

Static site for the DETOXY privacy policy. Generated by `tools/build_site.py` in the
App Factory repo; edit `store/privacy-policy.md` there, never these files.

## Publish (owner, about 5 minutes, free)

1. Sign in to github.com with **your own** account.
2. New repository → name `detoxy-privacy` → **Public** (free GitHub Pages needs a
   public repo) → Create.
3. "uploading an existing file" → drag in everything in this folder
   (`index.html`, `privacy/`, `help/`, `.nojekyll`, this README) → Commit changes.
4. Settings → Pages → Source: "Deploy from a branch" → Branch `main`, folder `/ (root)` → Save.
5. After a minute or two the policy is live at
   `https://<your-username>.github.io/detoxy-privacy/privacy/`.
   Open it on your phone to check, then paste that URL into Play Console →
   App content → Privacy policy, and into `store/PLAY_CONSOLE_CHECKLIST.md`.

## Updating

Rebuild with `python3 tools/build_site.py --release --pages <empty folder>` and upload
the new `index.html`, `privacy/index.html` and `help/index.html` over the old ones. The billing help
page is at `https://<your-username>.github.io/detoxy-privacy/help/`. Change the
"Effective date" in the policy whenever its meaning changes.
